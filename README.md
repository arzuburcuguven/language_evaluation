# Survey Results & Annotations

This repository contains the results and annotations from our survey on linguistic benchmarks.

## Contents

- **Results files** — Result files taken from benchmarks
- **Survey-yaml** — Provided the mapping from syntactic categories in studies to our syntactic labels .
- **`phenomena_table.csv`** — Full annotation data from the survey

## Usage

The YAML mapping files can be used to interpret the columns and values in the CSV. Each entry in the CSV corresponds to a benchmark annotated according to the schema defined in the mappings.
